# Nexus Defense

사방에서 몰려오는 적으로부터 중앙의 넥서스를 지켜내는 웹 타워 디펜스 게임.

**플레이**: https://chs034792-prog.github.io/Nexus-Defense/

의존성 없는 단일 HTML 파일(`index.html`)입니다. 빌드 과정이 없고, 파일을 브라우저로 열기만 하면 바로 실행됩니다. 저장은 브라우저의 `localStorage`를 사용합니다.

---

## 게임 방식

중앙에 넥서스가 있고, 적이 사방에서 넥서스를 향해 몰려옵니다. 넥서스는 사거리 안의 적을 자동으로 공격하며, 적이 넥서스에 닿으면 체력이 깎입니다. 체력이 0이 되면 게임이 끝나고, 도달한 웨이브에 비례해 **코어**를 받습니다. 코어는 판이 끝나도 사라지지 않아 영구 강화에 씁니다.

한 판(run) 안에서 모으는 **골드**는 그 판에서만 유효하고, **코어**는 계속 누적됩니다.

### 조작

| 조작 | 동작 |
|---|---|
| `Space` | 웨이브 즉시 시작 |
| `P` | 일시정지 / 해제 |
| `Esc` | 정보 창 닫기 (상점 화면에서는 메인으로) |
| `1`, `2` | 영웅 고용 |
| 넥서스 클릭 | 넥서스 강화 탭으로 전환 |
| 영웅/유닛 클릭 | 정보 창 열기 (게임 자동 정지) |
| 넥서스 정보 버튼 | 화면 우측하단, 현재 넥서스 능력치 확인 (게임 자동 정지) |

화면 상단 칩으로 배속 변경(x1~x5, x10), 일시정지, 메인으로 나가기를 할 수 있습니다.

## 웨이브

- 웨이브당 적 수: `6 + floor(웨이브 x 1.6)`
- 스폰 간격: `1.6 - 웨이브 x 0.014`초 (최소 0.24초, 웨이브 97에서 하한 도달)
- 클리어 보너스: `25 + 웨이브 x 6` 골드
- 웨이브가 끝나면 **2.5초** 뒤 다음 웨이브가 자동으로 시작됩니다
- 10의 배수 웨이브마다 보스가 추가로 등장합니다

### 적 등장 규칙

10웨이브마다 한 단계씩 올라가며, **인접한 두 단계**가 함께 등장합니다.

| 웨이브 | 등장 적 |
|---|---|
| 1~9 | 졸개(1) |
| 10~19 | 졸개(1), 질주(2) |
| 20~29 | 질주(2), 중갑(3) |
| 30~39 | 중갑(3), 독충(4) |
| 40~49 | 독충(4), 돌격병(5) |
| 50~59 | 돌격병(5), 철갑(6) |
| 60~69 | 철갑(6), 암살자(7) |
| 70~79 | 암살자(7), 파괴자(8) |
| 80~89 | 파괴자(8), 마법사(9) |
| 90+ | 마법사(9), 포격수(10) |

### 난이도 상승

세 가지가 겹쳐서 올라갑니다.

1. **웨이브당 체력 증가** — 모든 일반 적의 체력에 `1.005^웨이브` 배율. 이게 없으면 스폰 간격이 하한(0.24초)에 닿는 웨이브 97 이후로 난이도가 완전히 고정되어, 영구 강화가 쌓이면 판이 끝나지 않습니다.
2. **웨이브 40의 급상승** — 웨이브 40부터 모든 적(보스 포함)의 **체력과 공격력이 2배**가 됩니다.
3. **보스 성장** — 보스 체력 `417 x (웨이브/10)^1.35`, 공격력 `135 + (티어-1) x 30`.

## 넥서스

### 초기 능력치

| 항목 | 값 |
|---|---|
| 체력 | 200 |
| 공격력 | 10 |
| 공격속도 | 1.3 발/초 |
| 사거리 | 165 |
| 체력재생 | 0 |
| 시작 골드 | 40 |

사거리는 항상 화면에 원으로 표시됩니다. 영구 강화 상점에서 현재 넥서스 능력치를 확인할 수 있고, 게임 중에는 화면 우측하단 **넥서스 정보** 버튼으로 실시간 스탯을 볼 수 있습니다.

### 판 안에서의 강화 (골드)

비용은 `(5 + 레벨x5) x 1.15^레벨`로, 살수록 가팔라집니다. 횟수 제한은 없습니다.

| 항목 | 효과 |
|---|---|
| 공격력 강화 | 공격력 +2 |
| 공격속도 강화 | 초당 발사 +0.2 |
| 사거리 증가 | 사거리 +1 |
| 최대체력 증가 | 최대 체력 +5 · 즉시 회복 |
| 체력 재생 | 초당 HP +0.5 회복 |
| 수입 증대 | 웨이브 클리어 보상 +5% |

#### 드론 업그레이드 (수리공 배치 시)

지상 유닛 **수리공**을 배치하면 넥서스 강화 탭에 드론 관련 항목이 추가됩니다. 드론은 넥서스 주변을 선회하며, 부딪히는 적에게 접촉 피해를 줍니다.

| 항목 | 비용 | 효과 |
|---|---|---|
| 드론 추가 | 150G~ (최대 10기) | 선회 드론 +1 (충돌 피해 12, 궤도 반경 250) |
| 드론 공격력 | 60G~ | 드론 충돌 피해 +4 |
| 드론 속도 | 60G~ | 드론 선회 속도 +0.3 |

수리공을 해고하면 드론과 관련 업그레이드가 모두 초기화됩니다.

## 유닛 시스템

모든 유닛(영웅·지상)은 같은 **인구 풀**을 공유합니다. 시작 인구는 **1**이고, 영웅 탭의 **최대 인구 증가**로 늘립니다.

- 구입당 +2 (1 → 3 → 5 → 7 ...)
- 비용: `80 x 1.7^구입횟수` (80 → 136 → 231 → 393 ...)

같은 유닛을 또 고용하면 비용이 1.55배씩 오릅니다. 해고하면 투입 골드의 70%를 돌려받습니다.

유닛은 자기 배치 자리를 중심으로 한 원 안에서만 움직이며, 그 밖의 적은 쫓아가지 않습니다. 활동 반경은 화면에 점선으로 표시됩니다.

### 영웅 강화

영웅 탭의 **영웅 강화**로 보유한 모든 유닛의 공격력이 함께 오릅니다.

- 구입당 **+5%** (x1.00 → x1.05 → x1.10 ..., 배수가 아니라 더하는 방식)
- 비용: `60 x 1.18^구입횟수` (60 → 70 → 83 → 98 ...)

### 영웅 (영웅 병과 해금 필요 — 150,000 코어)

| 이름 | 고용 | 공격력 | 공속 | 사거리 | 이동 | 행동 |
|---|---|---|---|---|---|---|
| 순찰병 | 90G | 14 | 1.5 | 80 | 132 | 배치 자리에서 **265 반경**까지 나가서 싸움 |
| 저격수 | 260G | 95 | 0.45 | 265 | — | **제자리 고정**, 쫓아가지 않음 |

### 지상 유닛 (지상 병과 해금 필요 — 3,000 코어)

| 이름 | 고용 | 공격력 | 공속 | 사거리 | 이동 | 특수 능력 |
|---|---|---|---|---|---|---|
| 검사 | 100G | 14 | 1.5 | 80 | 132 | 범용 전투원, **265 반경** 활동 |
| 저격수 | 280G | 95 | 0.45 | 265 | — | **제자리 고정**, 원거리 저격 |
| 버퍼 | 220G | 6 | 1.2 | 80 | 120 | **적 감속**(40%, 2초) + **주변 초당 8 피해** 오라 (반경 80) |
| 수리공 | 400G | — | — | — | — | **1기 한정**, 전투 불가, 넥서스에 **드론 시스템** 해금 |

- **버퍼**: 투사체로 적을 느리게 하면서, 자기 주변 반경 80 안의 모든 적에게 초당 8의 지속 피해를 줍니다. 오라 범위는 화면에 점선 원으로 표시됩니다.
- **수리공**: 배치하면 넥서스 강화 탭에 드론 가동/드론 공격력/드론 사거리 업그레이드가 나타납니다. 해고하면 드론과 업그레이드가 모두 사라집니다.

### 지상군 강화

지상 탭 하단의 **지상군 강화**로 보유한 모든 지상 유닛의 공격력이 함께 오릅니다.

- 구입당 **+5%** (x1.00 → x1.05 → x1.10 ..., 배수가 아니라 더하는 방식)
- 비용: `50 x 1.18^구입횟수` (50 → 59 → 69 → 82 ...)

## 저장

### 진행 중인 판 이어하기

모바일 인앱 브라우저(카카오톡 등)는 다른 앱으로 전환하면 페이지를 통째로 종료시켜 판이 사라집니다. 이를 막기 위해 판의 뼈대를 따로 저장합니다.

- 저장 시점: 웨이브 클리어, 강화·고용·해고, 화면이 가려질 때(`visibilitychange`), 페이지가 내려갈 때(`pagehide`)
- 메인 화면에 **이어하기 (웨이브 N)** 버튼이 나타납니다
- 해당 웨이브의 **준비 단계부터** 다시 시작합니다. 진행 중이던 적·탄환은 복원하지 않습니다
- 브라우저가 경고 없이 즉시 종료되는 경우에도 최대 **웨이브 하나**만 잃습니다

### 백업 코드 (기기 간 이전)

`localStorage`는 브라우저마다 완전히 분리되어 있어, **카카오톡 인앱 브라우저와 크롬은 같은 주소여도 기록이 이어지지 않습니다.** 서버가 없으므로 코드를 복사해 옮깁니다.

메인 화면 → **코드 관리**
- **코드 복사** — 현재 진행도를 base64 코드로 만들어 클립보드에 복사 (인앱 브라우저에서 클립보드가 막히면 화면의 칸에서 직접 복사)
- **코드 불러오기** — 다른 브라우저에서 붙여넣어 복원

옮겨지는 것은 **영구 데이터(코어·최고 기록·영구 강화)**이며, 진행 중이던 판은 옮겨지지 않습니다.

> 이 코드는 단순 base64라 내용을 수정할 수 있습니다. 지인끼리 하는 캐주얼 플레이에는 문제없지만, 랭킹 경쟁이 필요하다면 서버(Supabase 등)가 필요합니다.

## 기술 메모

- 캔버스 내부 해상도는 960x720 고정이고, CSS로 화면 폭에 맞춰 축소됩니다. 클릭 좌표는 `getBoundingClientRect()` 비율로 환산하므로 어떤 크기에서도 정확합니다.
- PC에서는 CSS 미디어 쿼리(`min-width: 960px`)로 캔버스와 패널이 나란히 배치되어 한 화면에 들어옵니다.
- 배속은 한 프레임에 `update()`를 여러 번 호출하는 방식입니다. 자동 웨이브 카운트다운만은 배속과 무관하게 실제 시간으로 흐릅니다.
- 화면이 가려졌다 돌아오면 그 사이 흐른 실제 시간만큼 시뮬레이션해 따라잡습니다(최대 3시간, 계산 시간 상한 있음).
- 폰 뒤로가기로 메인에 돌아갈 수 있게 히스토리를 쌓아두며, 판이 진행 중이면 확인 창을 띄웁니다.
