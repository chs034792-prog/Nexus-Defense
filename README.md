# Nexus Defense

사방에서 몰려오는 적으로부터 중앙의 넥서스를 지켜내는 웹 타워 디펜스 게임.

**플레이**: https://chs034792-prog.github.io/Nexus-Defense/

의존성 없는 단일 HTML 파일(`index.html`)입니다. 빌드 과정이 없고, 파일을 브라우저로 열기만 하면 바로 실행됩니다. 저장은 브라우저의 `localStorage`를 사용합니다.

---

## 게임 방식

중앙에 넥서스가 있고, 적이 사방에서 넥서스를 향해 몰려옵니다. 넥서스는 사거리 안의 적을 자동으로 공격하며, 적이 넥서스에 닿으면 체력이 깎입니다. 체력이 0이 되면 게임이 끝나고, 도달한 웨이브에 비례해 **코어**를 받습니다. 코어는 판이 끝나도 사라지지 않아 영구 강화에 씁니다.

한 판(run) 안에서 모으는 **골드**는 그 판에서만 유효하고, **코어**는 계속 누적됩니다. **특수 코어**는 영웅 직업 변경에 사용되는 별도 재화입니다.

### 지역 선택 출격

영구 상점에서 지역 출격을 해금하면 해당 지역의 첫 웨이브부터 시작할 수 있습니다.

메인 화면의 **지역 정보** 버튼 오른쪽에 현재 선택된 지역이 표시됩니다. 이 버튼을 누르면 지역 목록이 열리고, 해금한 지역(잠기지 않은 항목)을 누르면 그 지역이 다음 출격의 시작 지점으로 바뀌면서 창이 닫힙니다. **출격** 버튼은 별도 선택 없이 바로 그 지역에서 시작합니다.

**해금 조건은 바로 앞 지역을 실제로 클리어(첫 도달)한 것 + 코어**입니다. 초원을 뺀 16개 지역 모두 영구 상점의 **지역 해금** 탭에서 살 수 있고, 비용은 그 지점까지 도달했을 때 받는 코어 보상의 2.5배(100 단위 반올림)로 자동 계산됩니다.

## 웨이브

- 웨이브당 적 수: `6 + floor(웨이브 x 1.6)`
- 스폰 간격: `1.6 - 웨이브 x 0.014`초 (최소 0.24초, 웨이브 97에서 하한 도달)
- 클리어 보너스: `25 + 웨이브 x 6` 골드
- 웨이브가 끝나면 **1초** 뒤 다음 웨이브가 자동으로 시작됩니다
- 10의 배수 웨이브마다 보스가 추가로 등장합니다
- 지역 경계(100, 200, 300...)를 넘어도 판이 끊기지 않고 **죽을 때까지 계속** 진행됩니다. 코어는 게임 오버 시에만 지급됩니다

### 적 등장 규칙

- **초원·숲 (웨이브 1~200)**: 10종 적, **10웨이브마다** 한 단계씩 올라가며, 보스도 **10웨이브마다** 등장. 원거리 적 포함.
- **산 이후 (웨이브 201~2500)**: 5종 적, **20웨이브마다** 한 단계씩 올라가며, 보스도 **20웨이브마다** 등장.

인접한 두 단계가 함께 등장합니다.

### 난이도 상승

네 가지가 겹쳐서 올라갑니다.

1. **웨이브당 체력 증가** — 모든 일반 적의 체력에 `1.005^웨이브` 배율 (지역마다 리셋).
2. **구간별 급상승** — 아래 웨이브를 넘길 때마다 모든 적(보스 포함)의 **체력과 공격력에 2배가 누적**됩니다.

   | 웨이브 | 누적 배율 |
   |---|---|
   | 1 ~ 39 | x1 |
   | 40 ~ 100 | x2 |
   | 101 ~ (숲 이후) | x4 |

3. **후반 완화** — 웨이브 50~100 구간에서 모든 적의 체력·공격력이 **35% 감소**합니다. 숲(웨이브 101~200) 보스의 체력은 **절반**으로 줄어듭니다.
4. **지역별 배율 (산~태양)** — 산을 기준으로 지역마다 체력·공격력 x2 누적. 태양은 산의 x256.
5. **보스 성장** — 보스 체력·공격력은 웨이브에 비례해 증가하며, 지역 배율도 적용.

### 숲 이후 공통 규칙 (웨이브 101~)

숲부터 모든 지역에 두 가지 규칙이 적용됩니다.

- **등장 수 리셋**: 각 지역의 첫 웨이브는 웨이브 1과 같은 수의 적이 나옵니다. 지역이 바뀔 때마다 개체수가 1~100 패턴으로 리셋됩니다.

## 넥서스

### 초기 능력치

| 항목 | 값 |
|---|---|
| 체력 | 200 |
| 공격력 | 10 |
| 공격속도 | 1.3 발/초 |
| 사거리 | 165 |
| 체력재생 | 0 |
| 시작 골드 | 40 |

사거리는 항상 화면에 원으로 표시됩니다. 영구 강화 상점에서 현재 넥서스 능력치를 확인할 수 있고, 게임 중에는 화면 우측하단 **넥서스 정보** 버튼으로 실시간 스탯을 볼 수 있습니다.

### 판 안에서의 강화 (골드)

비용은 `(5 + 레벨x5) x 1.15^레벨`로, 살수록 가팔라집니다. 횟수 제한은 없습니다. 각 항목 설명에 현재 넥서스 능력치가 실시간으로 표시됩니다.

| 항목 | 효과 |
|---|---|
| 공격력 강화 | 공격력 +2 |
| 공격속도 강화 | 초당 발사 +0.2 |
| 사거리 증가 | 사거리 +1 |
| 최대체력 증가 | 최대 체력 +5 · 즉시 회복 |
| 체력 재생 | 초당 HP +0.5 회복 |
| 수입 증대 | 웨이브 클리어 보상 +4% |

#### 드론 업그레이드 (영구 상점 「드론 해금」 필요)

**영구 상점에서 「드론 해금」을 구매해야** 넥서스 강화 탭에 드론 관련 항목이 나타납니다. 작업공을 배치해도 드론 해금을 구매하지 않았다면 드론 항목은 보이지 않습니다. 드론은 넥서스 주변을 선회하며, 부딪히는 적에게 접촉 피해를 줍니다.

| 항목 | 비용 | 효과 |
|---|---|---|
| 드론 추가 | `400 x 1.35^구입횟수` (최대 10기) | 선회 드론 +1 (충돌 피해 12, 궤도 반경 250) |
| 드론 공격력 | 60G~ | 드론 충돌 피해 +2 |
| 드론 속도 | 60G~ | 드론 선회 속도 +0.1 (기본 2.0) |

드론은 10기까지 겹쳐 쌓이는 강한 옵션이라 다른 강화(1.15배)보다 증가율이 가파릅니다.
400 → 540 → 729 → 984 → 1,328 → 1,793 → 2,421 → 3,268 → 4,412 → 5,957 (10기 총 약 21,800G)

작업공을 해고하면 드론과 관련 업그레이드가 모두 초기화됩니다.

## 유닛 시스템

모든 유닛(영웅·지상·기갑·공중)은 같은 **인구 풀**을 공유합니다. 시작 인구는 **1**이고, **각 병과 탭 하단의 최대 인구 증가**로 늘립니다.

- 구입당 +2 (1 → 3 → 5 → 7 ...), **최대 인구 50**에서 상한
- 비용: `150 + 100 x 구입횟수 x (구입횟수+1)` (150 → 350 → 750 → 1,350 → 2,150 ...)

같은 영웅을 또 고용하면 비용이 1.55배씩 오릅니다. 지상·기갑·공중 유닛은 **기준가만큼씩 선형으로** 오릅니다 (예: 500 → 1,000 → 1,500). 해고하면 투입 골드의 70%를 돌려받습니다.

유닛은 자기 배치 자리를 중심으로 한 원 안에서만 움직이며, 그 밖의 적은 쫓아가지 않습니다. 활동 반경은 화면에 점선으로 표시됩니다.

### 영웅 강화

영웅 탭의 **영웅 강화**로 보유한 모든 유닛의 공격력이 함께 오릅니다.

- 구입당 **+5%** (x1.00 → x1.05 → x1.10 ..., 배수가 아니라 더하는 방식)
- 비용: `60 x 1.18^구입횟수` (60 → 70 → 83 → 98 ...)

### 영웅 (영웅 해금 필요 — 8,000 코어, 200웨이브 클리어)

영웅은 넥서스 주변을 순찰하며 자동으로 적을 공격하는 특수 유닛입니다. **인구를 차지하지 않으며**, 한 번에 **1명만** 소환할 수 있습니다.

영웅 직업은 **영구 강화 상점의 영웅 탭**에서 선택합니다. 첫 선택은 무료이며, **직업을 변경하려면 특수 코어 1개**가 필요합니다. 선택한 직업은 영구 저장되며, 출격할 때마다 해당 직업의 영웅이 자동으로 소환됩니다. 인게임에서는 직업 변경이 불가능합니다.

| 직업 | 공격력 | 공속 | 사거리 | 이동속도 | 활동 반경 | 특수 능력 |
|---|---|---|---|---|---|---|
| 전사 | 45 | 1.8 | 40 | 220 | 전체 맵 | 근접 검 휘두르기, 높은 공격력, 빠른 이동 |
| 궁수 | 10 | 4.5 | 400 | 120 | 전체 맵 | 초장거리 화살, 빠른 연사, 낮은 단발 피해 |
| 마법사 | 60 | 0.5 | 200 | 100 | 전체 맵 | **에너지 볼트** 발사, **마나 소모** (12/발, 최대 100, 초당 5 재생), 광역 50, 감속 30% |

- **전사**: 빠른 이동속도로 적에게 달려들어 검을 휘둘러 공격. 사거리가 매우 짧지만 높은 공격력으로 보완. 공격 시 검 휘두르기 이펙트
- **궁수**: 초장거리(400)에서 화살을 빠르게 연사. 단발 피해는 낮지만 높은 공속(4.5)으로 보완. 화살 투사체로 표시
- **마법사**: 마나를 소모해 에너지 볼트를 발사하여 적을 제압하고 감속. 느린 공속이지만 높은 단발 피해. 마나가 부족하면 공격하지 않음

#### 경험치와 레벨

영웅은 적 처치 시 경험치를 **1**씩 획득합니다. 다음 레벨에 필요한 경험치는 `5 + 레벨 x 5`입니다 (Lv.1→2: 10, Lv.2→3: 15, Lv.3→4: 20 ...).

**경험치와 레벨은 직업별로 독립적으로 저장됩니다.** 전사로 Lv.5까지 올린 뒤 궁수로 전환해도 전사의 레벨은 유지되며, 다시 전사를 선택하면 Lv.5부터 시작합니다. 영구 강화 상점의 영웅 탭에서 각 직업의 현재 레벨과 경험치를 확인할 수 있습니다.

레벨업 시 능력치가 자동으로 성장합니다:

| 직업 | 레벨당 공격력 | 레벨당 공속 | 레벨당 이동속도 | 기타 |
|---|---|---|---|---|
| 전사 | +4 | +0.03 | +5 | — |
| 궁수 | +1 | +0.08 | +2 | — |
| 마법사 | +5 | +0.02 | — | 최대 마나 +5, 마나 재생 +0.3 |

#### 스킬 (Lv.30 해금)

레벨 30에 도달하면 직업별 고유 스킬이 해금됩니다. 화면 우측 하단에 스킬 버튼과 Auto 토글이 표시됩니다.

- **Auto ON**: 적이 존재하고 쿨다운이 끝나면 자동 사용
- **Auto OFF**: 스킬 버튼을 직접 눌러야 발동

| 직업 | 스킬 이름 | 쿨다운 | 효과 |
|---|---|---|---|
| 전사 | 파워 스트라이크 | 16초 | 큰 검을 휘둘러 반경 170 내 모든 적에게 공격력 x3 피해 |
| 궁수 | 연발샷 | 14초 | 가장 가까운 적에게 화살 6발을 연달아 발사 (타격당 공격력 x2) |
| 마법사 | 매직샷 | 18초 | 거대한 마법 구체를 발사해 착탄 지점 반경 110에 공격력 x5 피해 + 50% 감속 2.5초 |

- **파워 스트라이크**: 발동 시 캐릭터 주위로 크게 회전하는 검 이펙트가 표시된다
- **연발샷**: 단일 대상에게 짧은 간격(0.1초)으로 화살 6발이 연속 발사된다
- **매직샷**: 목표까지 날아가 폭발하는 대형 투사체로, 스플래시 범위 안의 적도 함께 피해를 입는다

영웅은 판이 끝나도 레벨이 유지되며, 새 판에서 저장된 레벨로 자동 소환됩니다.

#### 인게임 영웅 탭

영웅을 해금하면 게임 내 상점에 **영웅** 탭이 추가됩니다. 이 탭에서 확인할 수 있는 정보:

- **영웅 정보 패널** — 현재 영웅의 이름, 레벨, 경험치 바(진행률), 공격력·공속·사거리·이동속도·마나(마법사) 등 실시간 스탯
- **스킬 섹션** — 직업별 고유 스킬의 이름, 설명, 쿨다운, 피해배율, 해금 상태 (Lv.10 미만이면 잠김 표시)
- 인게임에서는 직업 변경 불가 — 영구 상점에서만 특수 코어로 전직 가능

### 지상 유닛 (지상 병과 해금 필요 — 2,500 코어)

| 이름 | 고용 비용 (1·2·3번째) | 공격력 | 공속 | 사거리 | 이동 | 특수 능력 |
|---|---|---|---|---|---|---|
| 검사 | 500 → 1,000 → 1,500 | 14 | 1.5 | 80 | 132 | 범용 전투원, **265 반경** 활동 |
| 저격수 | 750 → 1,500 → 2,250 | 95 | 0.45 | 265 | — | **제자리 고정**, 원거리 저격 |
| 버퍼 | 750 → 1,500 → 2,250 | 6 | 1.2 | 80 | 120 | **적 감속**(40%, 2초) + **주변 초당 8 피해** 오라 (반경 80) |
| 작업공 | 400G | — | — | — | — | **1기 한정**, 전투 불가 |

지상 유닛은 고용할 때마다 **기준가만큼씩** 더해집니다 (`기준가 x 보유수`). 작업공은 1기 한정이라 가격이 오르지 않습니다.

- **버퍼**: 투사체로 적을 느리게 하면서, 자기 주변 반경 80 안의 모든 적에게 초당 8의 지속 피해를 줍니다. 오라 범위는 화면에 점선 원으로 표시됩니다.
- **작업공**: 드론 시스템 자체는 **영구 상점의 「드론 해금」 구매가 있어야만** 넥서스 탭에 나타납니다 (작업공 배치만으로는 드론 항목이 열리지 않습니다). 작업공을 해고하면 드론과 업그레이드가 모두 사라집니다.

## 코어와 영구 강화

### 코어 획득

`10 x 클리어웨이브^1.3`

| 클리어 | 코어 |
|---|---|
| 10 | 199 |
| 20 | 492 |
| 30 | 843 |
| 50 | 1,665 |
| 100 | 3,981 |

- **게임 오버** 시에만 지급됩니다
- **뒤로가기·X로 나가는 것은 판을 끝내지 않습니다.** 현재 웨이브가 저장되고 메인의 **이어하기**로 돌아올 수 있어, 코어도 지급되지 않습니다.
- 클리어웨이브는 **이 판의 시작 웨이브를 기준으로 실제로 넘은 웨이브 수**입니다. 웨이브 1부터 시작한 판은 기존과 동일하지만, 지역을 사서 중간부터 시작한 판은 그 지역의 첫 웨이브가 0으로 취급됩니다.

## 운영자 모드 (테스트용)

주소 뒤에 **`?dev=1`** 을 붙이면 켜집니다.

```
https://chs034792-prog.github.io/Nexus-Defense/?dev=1
```

- **코어 무제한** — 메인·상점 진입 시 코어가 큰 값으로 고정됩니다
- **골드 무제한** — 판 안에서도 골드가 계속 채워져 강화를 마음껏 눌러볼 수 있습니다
- **웨이브 이동** — 메인 화면 하단 패널에 웨이브 번호를 넣으면 그 웨이브부터 바로 출격합니다
- **모든 지역 출격 개방** — 지역 해금 구매·클리어 조건을 무시합니다
- **영구 강화 초기화** — 강화·지역 해금 레벨을 모두 0으로 되돌립니다 (코어·최고 기록은 유지)
- 파라미터를 떼면 원래대로 돌아갑니다

**실제 기록은 오염되지 않습니다.**
- 부풀린 코어는 저장하지 않습니다 — 저장·백업 코드에는 `realCores`(실제 보유량)가 들어갑니다
- 운영자 모드로 만든 판은 스냅샷에 `dev: true` 가 붙고, `?dev=1` 을 뗀 상태에서는 **이어하기 목록에 뜨지 않습니다** (무한 골드가 일반 플레이로 넘어가는 것을 막습니다)

> 브라우저에서 도는 코드라 완전한 차단은 아니고, 일반 플레이어가 우연히 쓰지 않게 감춰두는 정도입니다.

- 판 진행 중에 나가도 끝나지 않으므로, 언제든 나갔다가 이어할 수 있습니다
- 해당 웨이브의 **준비 단계부터** 다시 시작합니다. 진행 중이던 적·탄환은 복원하지 않습니다
- 브라우저가 경고 없이 즉시 종료되는 경우에도 최대 **웨이브 하나**만 잃습니다

### 백업 코드 (기기 간 이전)

`localStorage`는 브라우저마다 완전히 분리되어 있어, **카카오톡 인앱 브라우저와 크롬은 같은 주소여도 기록이 이어지지 않습니다.** 서버가 없으므로 코드를 복사해 옮깁니다.

메인 화면 → **코드 관리**
- **코드 복사** — 현재 진행도를 base64 코드로 만들어 클립보드에 복사 (인앱 브라우저에서 클립보드가 막히면 화면의 칸에서 직접 복사)
- **코드 불러오기** — 다른 브라우저에서 붙여넣어 복원

옮겨지는 것은 **영구 데이터(코어·최고 기록·영구 강화)**이며, 진행 중이던 판은 옮겨지지 않습니다.

> 이 코드는 단순 base64라 내용을 수정할 수 있습니다. 지인끼리 하는 캐주얼 플레이에는 문제없지만, 점수 조작을 완전히 막으려면 서버 측 검증이 필요합니다.

### 온라인 랭킹

**Supabase**를 이용한 온라인 랭킹을 지원합니다. 메인 화면의 **랭킹** 버튼을 누르면 최고 웨이브 기준 상위 20명이 표시됩니다.

- **닉네임 입력** — 랭킹 창에서 닉네임을 입력하고 저장하면 등록됩니다
- **자동 갱신** — 게임 오버 시 닉네임이 등록되어 있으면 자동으로 최고 기록이 갱신됩니다
- **기기별 식별** — 브라우저마다 고유 ID가 생성되어 같은 닉네임으로 기록이 누적됩니다
- **운영자 모드 제외** — `?dev=1` 모드에서는 랭킹이 등록되지 않습니다

### 저장 데이터 보정

밸런스를 크게 바꿀 때 기존 기록을 한 번만 손봅니다. `save.mig` 에 적용된 단계를 남겨 같은 보정이 두 번 걸리지 않게 합니다.

| 단계 | 내용 |
|---|---|
| 1 | 강화 증가폭 절반화에 맞춰 **보유 코어를 1/10 로** 조정 |

백업 코드에도 `mig` 이 실려가므로, 다른 브라우저로 옮겨도 다시 깎이지 않습니다. 보정 이전에 뽑아둔 옛 코드(v1)를 불러오면 그때 한 번 적용됩니다.

## 밸런스 조정하기

숫자는 대부분 `index.html`의 "밸런스 데이터" 구역에 모여 있습니다.

| 상수 | 의미 |
|---|---|
| `CFG` | 넥서스 시작 능력치, 시작 골드, 환급률, 기본 인구 |
| `HEROES` | 영웅 능력치 (`hold`: 제자리 고정, `roam`: 활동 반경) |
| `HERO_CLASSES` | 영웅 직업 정의 (전사·궁수·마법사), 마법사는 마나 시스템 포함 |
| `GROUND_UNITS` | 지상 유닛 능력치 (`aura`: 오라 DPS, `unique`: 1기 제한, `noCombat`: 비전투) |
| `ENEMIES` | 적 기본 능력치 |
| `TIERS` | 적 단계 순서 (= 등장 순서) |
| `waveCount` / `waveGap` / `waveBonus` | 웨이브 물량·간격·보상 |
| `countWave` | 숲(101~) 이후 등장 수를 초원(1~100) 범위로 맞추는 웨이브 치환 |
| `ENEMY_HP_GROW` | 웨이브당 적 체력 증가율 (1.005) |
| `hpGrowthWave` | 숲(101~) 이후 체력 성장 곡선을 상대 웨이브로 맞추는 치환 |
| `HARD_STEPS` / `hardMul` | 구간별 급상승 단계 (웨이브 40, 101에서 각각 2배 누적) |
| `BOSS_HP_BASE` / `BOSS_HP_EXP` | 보스 체력 곡선 |
| `NEXUS_UPS` | 판 안에서의 넥서스 강화 (드론 업그레이드 포함) |
| `META` | 코어로 사는 영구 강화 (테크트리 해금 포함) |
| `metaCost` | 영구 강화 비용 — `기본가 x (레벨+1)` 선형 증가 |
| `MSTEP` | 영구 강화 레벨당 증가폭 (표시·적용이 함께 쓰는 단일 출처) |
| `DRONE` | 드론 기본값과 레벨당 증가폭 (표시·적용이 함께 쓰는 단일 출처) |
| `MIGRATION` / `migrate` | 저장 데이터 보정 단계 |
| `POP_UP` / `HERO_UP` / `GROUND_UP` | 인구·영웅·지상군 강화 비용과 증가폭 |
| `coreReward` | 코어 보상 공식 (입력값은 이 판의 시작 웨이브 기준 클리어 수) |
| `S.startWave` | 이 판이 시작된 웨이브 — 코어 보상 계산의 기준점 |
| `ZONE_META` | 초원을 뺀 모든 지역의 출격 해금 (조건·비용을 ZONES 로부터 자동 생성) |
| `ZONE_BOOST` | 지역 시작 시 넥서스 보정 (현재 숲만 있음) |
| `getSelectedZoneFrom` / `setSelectedZone` | 메인 화면에서 고른 출격 시작 지역 (localStorage에 유지) |
| `DEV` | 운영자 모드 여부 (`?dev=1`) |
| `forceAdminCores` / `forceAdminGold` / `realCores` | 운영자 모드의 무제한 자원과 실제 저장값 분리 |

## 기술 메모

- 캔버스 내부 해상도는 960x720 고정이고, CSS로 화면 폭에 맞춰 축소됩니다. 클릭 좌표는 `getBoundingClientRect()` 비율로 환산하므로 어떤 크기에서도 정확합니다.
- PC에서는 CSS 미디어 쿼리(`min-width: 960px`)로 캔버스와 패널이 나란히 배치되어 한 화면에 들어옵니다.
- 배속은 한 프레임에 `update()`를 여러 번 호출하는 방식입니다. 자동 웨이브 카운트다운만은 배속과 무관하게 실제 시간으로 흐릅니다.
- 화면이 가려졌다 돌아오면 그 사이 흐른 실제 시간만큼 시뮬레이션해 따라잡습니다(최대 3시간, 계산 시간 상한 있음).
- 폰 뒤로가기로 메인에 돌아갈 수 있게 히스토리를 쌓아두며, 판이 진행 중이면 확인 창을 띄웁니다.
